# rosters

A collection of pre-made agent rosters.

## Installation

Install the package from the repository root:

```bash
python -m pip install .
```

For development, install it in editable mode:

```bash
python -m pip install -e .
```

## Usage

The `rosters` command prints the absolute path to the installed package:

```bash
rosters
myteam list "$(rosters)/skills"
```
