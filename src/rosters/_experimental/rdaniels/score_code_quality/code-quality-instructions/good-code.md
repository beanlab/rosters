# Good Code Instructions

Write clear, focused, maintainable code in the project’s established style.
Understand the requested behavior and existing interfaces before coding. Use
descriptive names, cohesive functions, explicit error handling, and type hints
where the language supports them. Preserve or add tests when tests are part of
the request, and never claim that tests passed unless you actually ran them.
Avoid unrelated rewrites, respect existing dependencies, and leave only the
requested program files in the assigned result directory.
